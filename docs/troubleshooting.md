# Симптом → причина

Перелік поломок, які нічого про себе не повідомляють: сторінка віддається з кодом 200, у лозі
порожньо, у консолі браузера теж. Пояснення — у відповідному розділі, тут лише маршрут до
нього.

## Сторінка

| Симптом | Ймовірна причина | Куди |
| ------- | ---------------- | ---- |
| Півсторінки зникло, розмітка обривається посеред тексту | `TplMod` не зміг розібрати шаблон і надрукував лише те, що встиг: `<` поза відкривальним `{if}`, змінне ім'я тега або тег, відкритий в одній гілці `{if}` | [tpl-modifications.md](tpl-modifications.md#пастки-як-модифікація-тихо-ламає-сторінку) |
| Модифікація `.tpl` з модуля не застосувалась | не почищено `compiled/`; або `childrenFind` нічого не знайшов і зміну пропущено мовчки | [tpl-modifications.md](tpl-modifications.md#налагодження) |
| Фатальна помилка, але HTTP-статус 200 | під `debug_mode` фатал друкується в тіло, статус ніхто не змінює; або тіло вже відправлене й `header()` не спрацював | [configuration.md](configuration.md#пастка-фатал-під-debug_mode-віддає-http-200) |
| Порожня біла сторінка без жодного повідомлення | `debug_mode = false`, помилка пішла в `Okay/log/` | [configuration.md](configuration.md#debug_mode) |
| Тег модуля в шаблоні нічого не друкує | модуль вимкнений — його Smarty-плагіни підмінені заглушками | [smarty-plugins.md](smarty-plugins.md#плагіни-вимкнених-модулів) |
| `{date('Y-m-d')}` виводить рядок `Y-m-d` | у Smarty 5 виклик із дужками резолвиться як модифікатор і потрапляє в наш плагін `date` | [smarty-plugins.md](smarty-plugins.md#пастка-smarty-5-модифікатор-у-позиції-виклику) |
| Лічильник чи прапорець, накопичений у `{function}`, зовні має старе значення | Smarty 5 тримає присвоєння всередині `{function}` локальними | [templates.md](templates.md#function-тримає-присвоєння-локальними) |
| `{$arr|reset}` і подібне перестало працювати | модифікатор отримує копію, а не посилання; заміни — `\|first` і `\|first_key` | [templates.md](templates.md#модифікатори-що-працюють-через-посилання-не-працюють) |

## Стилі

| Симптом | Ймовірна причина | Куди |
| ------- | ---------------- | ---- |
| Колір із налаштувань теми не підставився | у рядку більше одного `var()`, або використано `var(--x, fallback)`, який не резолвиться взагалі | [assets.md](assets.md#пастки-css-компілятора) |
| Частина CSS зникла після складання | `/*` усередині `url()` чи рядка сприйнято як початок коментаря | [assets.md](assets.md#пастки-css-компілятора) |
| Оголошення злиплось із наступним | компілятор склеює рядки без роздільника — правило, розірване між рядками, ламається | [assets.md](assets.md#пастки-css-компілятора) |
| Скомпільований `{js}`-файл не знайшовся в `cache/js/` | файли, підключені плагіном `{js}`, кладуться в `cache/css/` | [assets.md](assets.md#smarty-плагіни-js-і-css) |

## База й дані

| Симптом | Ймовірна причина | Куди |
| ------- | ---------------- | ---- |
| `find()` тягне всю таблицю | без `limit` і `page` `LIMIT` не додається взагалі — «ліміт 100» стосується лише пари з `page` | [entities.md](entities.md#пастка-ліміт-100-за-замовчуванням) |
| Фільтр не спрацював, помилки немає | ім'я фільтра не збіглося з жодним полем — такий ключ мовчки ігнорується; або значенням був порожній масив, що означає «без умови» | [entities.md](entities.md#магічні-фільтри) |
| Після збереження в адмінці текст іншою мовою змінився | базова таблиця дзеркалить головну мову (найменша `position`), і `update()` пише мовні поля туди лише з неї | [entities.md](entities.md#базова-таблиця-дзеркалить-головну-мову) |
| Фільтр із кількома значеннями віддає не те | масив у другому аргументі `where()` підставляється текстово; ім'я плейсхолдера виявилось префіксом іншого | [entities.md](entities.md#пастка-імена-плейсхолдерів-у-aurasqlquery-3) |
| `TypeError` у запиті, якого не бачить phpstan | скалярний другий аргумент `where()` — aura 3 чекає масив | [entities.md](entities.md#пастка-імена-плейсхолдерів-у-aurasqlquery-3) |

## Модулі

| Симптом | Ймовірна причина | Куди |
| ------- | ---------------- | ---- |
| Встановлення модуля падає на `CREATE TABLE` | `update_x_y_z()` виконуються і на чистій інсталяції, а `migrateEntityTable()` не ідемпотентний | [modules/lifecycle.md](modules/lifecycle.md#встановлення) |
| Кнопка оновлення нічого не робить | версія в `module.json` не з трьох чисел, або `ok_modules.version` порожня | [modules/lifecycle.md](modules/lifecycle.md#оновлення) |
| `DEFAULT` поля не застосувався | сеттер типу викликано після `setDefault()` — він скидає значення за замовчуванням | [modules/migrations.md](modules/migrations.md#пастки) |
| Розширення кладе запит на конструкторі | клас не оголошений в `Init/services.php`, тому створюється через `new` без аргументів | [modules/extenders.md](modules/extenders.md#реєстрація) |
| Маршрут модуля не працює | модуль вимкнений — його маршрути позначаються як `mock` | [routes.md](routes.md#маршрут-у-модулі) |
| Налаштування модуля оплати не показує потрібний тип поля | шаблон способу оплати ігнорує атрибут `type` і дивиться лише на кількість `<options>` | [modules/structure.md](modules/structure.md#settingsxml--налаштування-оплати-й-доставки) |

## Оточення й консоль

| Симптом | Ймовірна причина | Куди |
| ------- | ---------------- | ---- |
| `./ok` падає фатально на будь-якій команді | якась команда лишилась без `#[AsCommand]` — це кладе застосунок ще на реєстрації | [cli.md](cli.md#своя-команда) |
| «service class does not exist» після зміни гілки | застарілий `vendor/` — потрібен `composer install` | [di.md](di.md#помилки-які-видає-контейнер) |
| Параметр із `{%…%}` приїхав у сервіс необробленим рядком | підстановка налаштувань працює лише в `calls`, не в `arguments` | [di.md](di.md#параметри) |
| Тест падає на застарілому методі | `failOnDeprecation = true` у `phpunit.xml` | [testing.md](testing.md#phpunit-13) |
| Задача планувальника не виконується | задачі існують лише після підняття модулів; або модуль вимкнено | [cli.md](cli.md#реєстрація-задачі) |

## Вітрина після оновлення безпеки

| Симптом | Ймовірна причина | Куди |
| ------- | ---------------- | ---- |
| Кошик, список бажань чи порівняння мовчки не працюють | тема шле GET замість POST або не передає `customer_csrf_token` | [theme-porting.md](theme-porting.md) |
| Мутуючий запит вітрини повертає 405 або 403 | не POST або невалідний токен | [controllers.md](controllers.md#мутації-вітрини) |
| Форма адмінки віддає 403 `Session expired` | у формі немає `session_id` або токен застарів | [modules/backend.md](modules/backend.md#csrf) |
| JS перестав читати куку кошика | куки отримали `HttpOnly` | [UPGRADE-security.md](UPGRADE-security.md) |
| Подвійний клік або `F5` створює другий запис — замовлення, заявку, відгук, коментар | у формі немає `{form_token}` — працює менш точний запасний шлях | [theme-porting.md](theme-porting.md#4-одноразовий-токен-у-формах-що-пишуть) |
| Форма коментаря, зворотного дзвінка чи швидкого замовлення віддає 403 | ці форми тепер теж перевіряються — у них немає `customer_csrf_token` | [theme-porting.md](theme-porting.md#1-токен-у-кожній-формі-що-щось-змінює) |
| Друга відправка форми мовчки нічого не робить, хоча дані нові | збігся запасний відбиток: те саме тіло запиту в межах вікна — 1 хв для заявки, відгуку, коментаря, 10 хв для оформлення | [theme-porting.md](theme-porting.md#4-одноразовий-токен-у-формах-що-пишуть) |
| Форма показує «Не вдалося зберегти» | запис не пройшов — причина в `Okay/log/`, поряд із рядком, який називає товар чи сторінку | [UPGRADE-security.md](UPGRADE-security.md#24-невдалий-запис-більше-не-виглядає-успіхом) |
| Замість тексту помилки у формі порожня плашка | тема не має гілки `$error=='not_saved'` | [theme-porting.md](theme-porting.md#41-код-помилки-not_saved) |
| Завантажений у `files/` `.html` відкривається в браузері | конфіг nginx на сервері не оновлений: deny-правило для `files/` не спрацьовувало через прив'язку регулярки | [UPGRADE-security.md](UPGRADE-security.md#15-deny-правила-nginx-не-діяли) |

## Імпорт і експорт

| Симптом | Ймовірна причина | Куди |
| ------- | ---------------- | ---- |
| Колонки CSV не зіставляються, файл виглядає правильним | BOM від Excel приклеївся до назви першої колонки, або в файлі не той роздільник | [import.md](import.md#що-відбувається-з-файлом-на-вході) |
| Уся шапка імпорту потрапила в одну колонку | роздільник у файлі не `;` — нормалізатор визначає його за заголовком | [import.md](import.md#що-відбувається-з-файлом-на-вході) |
| Скрипт, що читає вигрузку, спотикається на першому полі | файл тепер UTF-8 **з BOM** | [export.md](export.md#формат-файлу) |
| У вигрузці перед значенням з'явився апостроф | екранування значень, схожих на формулу — `=`, `+`, `-`, `@` | [export.md](export.md#формат-файлу) |
