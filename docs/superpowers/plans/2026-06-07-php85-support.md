# PHP 8.5 Support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add official, verified PHP 8.5 support to the OkayCMS fork without unrelated modernization.

**Architecture:** A new independent `php85` Docker service runs alongside the existing `php74` service for parallel verification. The `composer.json` minimum is raised to `^8.2` (7.4 dropped). A new GitHub Actions CI matrix verifies PHP 8.2–8.5. Static analysis (PHPStan baseline + PHPCompatibility) and PHPUnit gate the work. Compatibility fixes are discovered via an audit phase and applied as minimal, test-backed changes.

**Tech Stack:** PHP 8.5, Docker Compose, Composer, PHPUnit 9.5, PHPStan, PHPCompatibility (phpcs), GitHub Actions, MariaDB, Smarty, Symfony 5 components, Aura.Sql.

**Spec:** `docs/superpowers/specs/2026-06-07-php85-support-design.md`

## Phase 1 — Docker environment for PHP 8.5

### Task 1: Create the PHP 8.5 Docker image

**Files:**
- Create: `dev/docker/php/8.5/Dockerfile`
- Reference: `dev/docker/php/7.4/Dockerfile` (mirror its extensions)

- [ ] **Step 1: Write the Dockerfile**

Create `dev/docker/php/8.5/Dockerfile`:

```dockerfile
FROM php:8.5-fpm

RUN apt-get update && \
    apt-get install -y \
        zlib1g-dev \
        libzip-dev \
        libxml2-dev \
        libssl-dev \
        libxslt-dev

RUN /usr/local/bin/docker-php-ext-install mysqli pdo pdo_mysql xmlwriter zip

# Install GD
RUN apt-get install -y libfreetype6-dev libjpeg62-turbo-dev libpng-dev libwebp-dev libxmp-dev
RUN docker-php-ext-configure gd \
                    --prefix=/usr \
                    --with-jpeg \
                    --with-webp \
                    --with-freetype;
RUN docker-php-ext-install gd

# Install XSL
RUN docker-php-ext-install xsl

# Install Xdebug (3.x for PHP 8.x). If no 8.5-compatible release exists, comment these two lines out.
RUN pecl install xdebug \
    && docker-php-ext-enable xdebug

# Install Composer
RUN curl -sS https://getcomposer.org/installer | php -- --install-dir=/usr/local/bin --filename=composer

RUN usermod -u 1000 www-data
RUN groupmod -g 1000 www-data
```

- [ ] **Step 2: Build the image to verify it compiles**

Run: `cd dev && docker compose build php85` (after Task 2 adds the service) — or temporarily `docker build -t okay-php85-test dev/docker/php/8.5`
Expected: build succeeds. If `php:8.5-fpm` tag is missing, fall back to `php:8.5-rc-fpm`/`php:8.5.0-fpm` and note it. If Xdebug `pecl install` fails (no 8.5 release), comment out the two Xdebug lines and rebuild.

- [ ] **Step 3: Commit**

## Phase 4 — CI

### Task 6: Add GitHub Actions workflow

**Files:**
- Create: `.github/workflows/ci.yml`

- [ ] **Step 1: Write the workflow**

Create `.github/workflows/ci.yml`:

```yaml
name: CI

on:
  push:
    branches: [ master ]
  pull_request:

jobs:
  tests:
    runs-on: ubuntu-latest
    strategy:
      fail-fast: false
      matrix:
        php: ['8.2', '8.3', '8.4', '8.5']
    name: PHP ${{ matrix.php }}
    steps:
      - uses: actions/checkout@v4

      - name: Setup PHP
        uses: shivammathur/setup-php@v2
        with:
          php-version: ${{ matrix.php }}
          extensions: simplexml, xmlreader, pdo, json, curl, mbstring, zip, gd, xsl
          coverage: none

      - name: Validate composer.json
        run: composer validate --strict

      - name: Install dependencies
        run: composer install --no-interaction --prefer-dist

      - name: PHPStan
        run: vendor/bin/phpstan analyse --no-progress

      - name: PHPCompatibility
        run: vendor/bin/phpcs -p

      - name: PHPUnit
        run: vendor/bin/phpunit
```

Note: PHPStan/PHPCompatibility steps require Phase 7 dev deps + configs. If running CI before Phase 7, comment those two steps out and re-enable in Phase 7's commit.

- [ ] **Step 2: Lint the workflow locally (syntax sanity)**

Run: `cat .github/workflows/ci.yml` and verify YAML indentation; optionally `docker compose exec php85 php -r "var_dump(yaml_parse_file('/var/www/html/.github/workflows/ci.yml'));"` if the yaml ext is available, otherwise visual check.
Expected: valid YAML structure.

- [ ] **Step 3: Commit**

```bash

git commit -m "ci(php85): add PHP 8.2-8.5 test matrix workflow"
```

- [ ] **Step 1: Reproduce**

- [ ] **Step 2: Write a failing test (where the issue is testable)**

Add a test asserting the correct behavior. For deprecations surfaced only at runtime, prefer a unit test around the affected method. Example shape:

```php
public function testNoDeprecationOnAffectedPath(): void
{
    $result = (new SubjectClass())->affectedMethod($input);
    $this->assertSame($expected, $result);
}
```

If the issue is not unit-testable (e.g. an extender wiring deprecation), document why and rely on PHPUnit-wide deprecation-to-exception + PHPCompatibility as the gate.

- [ ] **Step 3: Run the test to confirm it fails**

Run: `cd dev && docker compose exec php85 php vendor/bin/phpunit --filter testNoDeprecationOnAffectedPath`
Expected: FAIL (reproduces the 8.5 issue).

- [ ] **Step 4: Apply the minimal fix**

Make the smallest change that resolves the 8.5 incompatibility. Root cause + why-8.5-exposes-it goes in the commit body. No unrelated edits.

- [ ] **Step 5: Run the test to confirm it passes**

Run: `cd dev && docker compose exec php85 php vendor/bin/phpunit --filter testNoDeprecationOnAffectedPath`
Expected: PASS.
