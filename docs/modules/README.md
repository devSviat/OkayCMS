# Модулі

Модуль — це каталог `Okay/Modules/<Vendor>/<Module>/` з певною структурою. У ньому можуть
жити контролери, сутності, шаблони, стилі, скрипти, переклади й міграції. Така інкапсуляція
дозволяє переносити модуль між магазинами.

Модуль — **єдиний дозволений спосіб змінювати поведінку системи**. Правити файли ядра, теми
чи чужого модуля не можна: наступне оновлення перезапише зміни. Замість цього є розширення
(для PHP) і блок `modifications` у `module.json` (для шаблонів).

## Модулі в цьому репозиторії

Вендор один — `OkayCMS`. Приклади, на які посилається розділ:

| Модуль | Чим корисний як приклад |
| ------ | ----------------------- |
| `AdminGuide` | мінімальний модуль: 8 файлів, `Init.php` на 23 рядки |
| `FAQ` | своя сутність, два контролери адмінки, пункт меню, сторінка вітрини через маршрут |
| `Banners` | сервіси й параметри модуля, розширення з ін'єкцією залежностей |
| `NovaposhtaCost` | найповніший: міграції, поля в чужих сутностях, 14 розширень, блоки з колбеками, планувальник, два `update_x_y_z()` |
| `LiqPay`, `Fondy`, `WayForPay`, `RozetkaPay` | модулі оплати з `settings.xml` і `PaymentForm` |
| `DeliveryFields`, `FastOrder` | модифікації `.tpl` через `module.json` |

## Обмеження

- Не редагувати файли ядра, теми й чужих модулів.
- Ліцензійний гейт: модуль, який не проходить перевірку ліцензії, **не запускається взагалі** —
  його `init()` не викликається.
- Модулі адмінки піднімаються навіть вимкненими (щоб їх було видно в списку), тож `init()`
  вимкненого модуля в адмінці все одно виконається — його маршрути при цьому позначаються як
  мок і не працюють.
